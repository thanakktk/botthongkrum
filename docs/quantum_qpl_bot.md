## 1. "Quantum trading" ที่นำมาใช้คืออะไร

ในวงการเทรดคำว่า quantum trading มีอย่างน้อย 3 ความหมาย:

| ความหมาย | ใช้ในบอทนี้? |
|---|---|
| **Quantum Finance ของ Raymond S. T. Lee** (Springer 2019) — ราคาเป็น "อนุภาคควอนตัม" ในบ่อศักย์ anharmonic oscillator ระดับพลังงานที่ไม่ต่อเนื่องกลายเป็นแนวรับ-แนวต้าน "Quantum Price Levels" | **ใช่** — นี่คือแกนของบอท |
| Quantum Trading ของ Fabio Oreste (สนามโน้มถ่วง, quantum lines, มุมเวลา-ราคา) | ไม่ — เป็นเทคนิค discretionary/แนว astro ทดสอบเชิงระบบไม่ได้ |
| Quantum computing สำหรับ portfolio optimisation (QAOA, annealing) | ไม่ — ไม่เกี่ยวกับสัญญาณเข้าออกของสินค้าตัวเดียว |

### สูตรของ Lee ที่ใช้ (ยืนยันจากเอกสารต้นฉบับ)

1. ผลตอบแทนรายวันมาตรฐาน `z = r / σ` ถือเป็นอนุภาคในศักย์ `V(z) = z²/2 + λ z⁴`
2. แก้สมการ Schrödinger `-½ψ'' + Vψ = Eψ` ได้ระดับพลังงาน `E₀ < E₁ < E₂ …`
   (ใน `quantum.py` แก้เชิงตัวเลขด้วยการ diagonalise เมทริกซ์ 60×60 บนฐาน harmonic oscillator —
   ตรวจกับค่าตำรา Bender–Wu ที่ λ=0.1: E₀=0.55915, E₁=1.76950 ✔)
3. **Quantum Price Return** `QPR(n) = E(n)/E(0)`
4. **Quantum Price Level** `QPL(±n) = P₀ × (1 ± 0.21 · σ · QPR(n))`
   P₀ = ราคาปิดของวันก่อน, σ = ค่าเบี่ยงเบนมาตรฐานของผลตอบแทนรายวัน, 0.21 = ค่าคงที่เชิงประจักษ์ของ Lee
5. λ ประมาณจาก kurtosis ของผลตอบแทน (ground state ของ oscillator มี kurtosis ลดลงจาก 3 เมื่อ λ โต)

ที่ λ=0 (harmonic) `QPR = 1,3,5,7,…` ดังนั้นบันไดราคาอยู่ห่าง P₀ ที่ 0.21σ, 0.63σ, 1.05σ, 1.47σ …
ทอง σ_daily ≈ 0.8 % ที่ราคา 4,000 → ขั้นละประมาณ $17

**ข้อค้นพบสำคัญ:** ผลตอบแทนทองมีหางหนา (kurtosis > 3) เกือบตลอด แต่ตระกูล anharmonic oscillator
สร้างได้เฉพาะ kurtosis ≤ 3 ⇒ λ ถูก clip เป็น 0 ใน 99 % ของสัญญาณ ในทางปฏิบัติ "บันไดควอนตัม"
ของทองจึงเป็นบันได harmonic ที่ระยะห่างเท่ากัน (ยืนยันแล้วว่า λ=0 กับ λ=fit ให้ผลเหมือนกันทุกตัวเลข)

## 2. กฎการเทรดของบอท (`quantum_qpl`, ค่า default ที่ validate แล้ว)

- ไทม์เฟรม H4 ดูเฉพาะแท่งที่ปิดแล้ว (เหมือน H4 trend bot) ใช้ 200 แท่งล่าสุดที่ main_loop ส่งให้
- ทุกแท่ง: P₀ = ปิดวันก่อน, σ = std ของ log-return H4 120 แท่ง × √6, สร้างบันได QPL(±1..±12)
- **เข้า BUY** เมื่อแท่ง H4 ปิด *ทะลุขึ้น* QPL(+3) เป็นครั้งแรก (แท่งก่อนยังปิดต่ำกว่า) = "กระโดดข้ามระดับพลังงาน"
  และราคาอยู่เหนือ EMA50, และไม่เกิน QPL(+4) (ไม่ไล่ราคาที่พุ่งไปไกลแล้ว)
- **SL** = QPL(0) = P₀ (ต่ำลง 3 ขั้น) · **TP** = QPL(+9) (ขึ้นอีก 6 ขั้น) ⇒ ประมาณ 2R
- ถือทีละ 1 ไม้, ความเสี่ยง 1 % ของ equity ต่อไม้, มี drawdown throttle เหมือนบอท H4
- **BUY เท่านั้น** — ดูเหตุผลข้อ 4

ตัวแปรที่มีให้ทดลอง: `k_in` (ระดับที่ต้องทะลุ), `sl_levels`, `tp_levels`, `trend_n`, `lam`, `side`, และ
`mode="bounce"` (`quantum_qpl_bounce`: แทงสวนเมื่อไส้เทียนแตะ QPL(−3) แล้วปิดกลับขึ้นมา)

## 6. ข้อควรระวังก่อนใช้เงินจริง

1. **นี่คือระบบ trend-following ฝั่งซื้อที่แต่งชุดควอนตัม** — ตัวเลขใกล้เคียง breakout_sr/donchian ของบอท H4
   (WR ~40 %, W/L ~1.8, PF ~1.3) ไม่ใช่ระบบ win rate สูง หากต้องการ WR 60–70 % ต้องยอมรับ W/L < 0.6 และ PF ≈ 1
2. **BUY-only พึ่งขาขึ้นระยะยาวของทอง** ปี 2013 (ทองลง 28 %) บอทขาดทุน 6 % ถ้าทองเข้า bear market หลายปี คาดว่าจะแพ้ต่อเนื่อง
3. ผลเป็นไม้ละ 1 % ทบต้น ไม่มี DD throttle ในการทดสอบ; บอทสดมี throttle (×0.5 ที่ −20 %, ×0.25 ที่ −35 %) จึง DD จริงต่ำกว่านิดหน่อย
4. ตอนสด main_loop ใช้ SL ของ strategy แต่ TP = 2R จาก `--tp2-r 2.0` (ตั้ง `--tp1-r 2.0` เท่ากันเพื่อไม่ให้มี partial) ซึ่งเท่ากับ 6 ขั้นบันไดเฉพาะเมื่อ λ=0 (เกือบทุกครั้ง)
5. ข้อมูลทดสอบเป็น server time ของผู้ให้ข้อมูล ขอบวัน (P₀) อาจเหลื่อมจากของ VT Markets 1–2 ชม.
6. ยังไม่ได้รันคู่กับบอท H4 ในบัญชีเดียวกันในการทดสอบ — สัญญาณของ `quantum_qpl` ทับซ้อนกับ breakout ของ H4 บางส่วน
   จึงอย่าคิดว่าเปิดทั้งสองแล้ว edge จะบวกกันเต็ม ๆ

แหล่งอ้างอิงทฤษฎี: Lee, R.S.T. *Quantum Finance: Intelligent Forecast and Trading Systems*, Springer 2019, บทที่ 4–5
(Quantum Finance Theory / Quantum Price Levels) และการอภิปรายสูตร QPR บน Physics Forums (thread 990012)

## 7. เพิ่มบริบท SMC: LQ / BOS / CHoCH / Supply-Demand (อัปเดต 2026-09-22)

โมดูล `smc.py` อ่านแท่ง H4 200 แท่งเดียวกับ strategy แล้วสร้างบริบท (ไม่มี lookahead: swing ยืนยันหลังผ่านไป 3 แท่ง):

| องค์ประกอบ | นิยามในโค้ด | พารามิเตอร์ใน `QuantumPriceLevel` |
|---|---|---|
| **BOS** (Break of Structure) | ปิดทะลุ swing high/low ล่าสุด *ตามทิศ* เทรนด์ | `smc_bos=True` (ต้องเป็น trend เดียวกับไม้), `bos_max_age` จำกัดอายุการทะลุ |
| **CHoCH** (Change of Character / "ช็อค") | การปิดทะลุ swing *สวน* เทรนด์ครั้งแรก → เปลี่ยน trend | รวมอยู่ใน `smc_bos` (last_event = `choch_up`/`choch_dn`) |
| **LQ** (liquidity sweep) | ไส้เทียนทะลุ swing low/high ที่ยังไม่ถูกทำลาย (รวม equal lows/highs ภายใน 0.15 ATR) แล้วปิดกลับเข้ามา | `smc_lq=True`, `lq_lookback` (แท่ง) |
| **Supply/Demand zone** (order block) | แท่งสีตรงข้ามแท่งสุดท้ายก่อน displacement ≥ 1.5 ATR ที่ทะลุ swing; โซนตายเมื่อมีแท่งปิดทะลุ | `smc_zone=True`, `zone_atr` (ไม้ต้องอยู่ห่างโซนไม่เกิน N ATR), `sl_mode="zone"` วาง SL ใต้โซน |

ทุกไม้ใน `reports/quantum_qpl*_trades*.csv` มีคอลัมน์ `smc` บอกว่าผ่าน gate อะไร (เช่น `bos_up|lq4|zone*`)
