### เป้ารายวัน (DailyGoal) — มีทั้งใน backtest และบอทสด

- `--daily-target-pct 0.01`: เมื่อ equity สูงกว่ายอด balance ตอนเที่ยงคืน CET ≥ +1 % → ปิดไม้ค้างล็อกกำไร แล้วไม่เปิดไม้ใหม่จนวันถัดไป
- `--daily-stop-pct 0.01`: ต่ำกว่า −1 % → ปิดทุกไม้ หยุดจนวันถัดไป
- ไม้ค้างถูกปิดที่แท่งสุดท้ายของวัน (ไม่ถือข้ามคืน) ใน backtest; ของสดใช้ session flatten ของ compliance engine
- ทุกครั้งที่ล็อกจะเขียน audit `daily_goal` และส่งแจ้งเตือน

### ทำไมถึงแพ้ (ตรวจแล้วไม่ใช่บั๊ก)

- ที่ TP = 1.5×SL การเดินสุ่มให้ WR ≈ 40 % พอดี (1/(1+1.5)) → ผลจริง 38–40 % = สัญญาณไม่มีข้อมูลทำนาย
- ต้นทุน $0.25 ต่อไม้ เทียบ ATR M15: ปี 2015–2019 ATR ≈ $1.5–2.5 → ต้นทุน 10–17 % ของ R ทุกไม้ → −0.10 ถึง −0.17R ตรงกับที่วัดได้
- ปี 2025 ATR ≈ $5–10 → ต้นทุนเหลือ 3–5 % → เท่าทุน ไม่ใช่กำไร
- ที่ cost $0.45 (สเปรดแบบ FTMO) แย่ลงอีก: PF 0.58

## 4. คำแนะนำ

1. **อย่าใช้เงินจริงกับ intraday_momentum / intraday_pullback** — ไม่มีชุดค่าใดใน 11 ปีที่ PF > 0.82; ปี 2025 ที่ดูเท่าทุนคือปีที่ผันผวนสูงผิดปกติ
2. ถ้าต้องการ "มีไม้ให้ดูทุกชั่วโมง" ให้รันบน **demo** ผ่าน `run_xau_intraday.ps1` เพื่อดูจังหวะและระบบเป้ารายวันทำงาน (มันแจ้งเตือนตอนถึงเป้า/ลิมิต)
3. ถ้าต้องการกำไรจริงแต่ยังเป็นรายวัน: `session_breakout` NY-only มีไม้ ~4/สัปดาห์ และเท่าทุน; ใช้ต่อเมื่อยอมรับว่าเป็นการทดลอง
4. เป้ารายวัน (`--daily-target-pct / --daily-stop-pct`) ใช้กับบอทตัวไหนก็ได้ รวมถึง H4 trend และ quantum — เป็นตัวคุมความเสี่ยงรายวันที่ดี แม้บนบอทที่มี edge จะตัดกำไรวันดีออกบ้าง
5. ความถี่กับ edge สวนทางกันบนทอง: ยิ่งไทม์เฟรมสั้น ต้นทุนต่อ R ยิ่งสูง ผลทดสอบทั้งหมดของโปรเจกต์ (M5/M15 เดิม, intraday ชุดนี้, H4) ชี้ทางเดียวกัน

## 5. ชุด "ไม้ทุกชั่วโมง, หลายไม้, hedge ได้, ถือ 3–4 ชม." + EA (อัปเดต 2026-09-23)

โจทย์ที่ปรับ: ไม่จำกัดไม้เดียว, hedge ได้ (ต้องปิดทั้งชุดเมื่อกำไร), ไม่ต้องปิดจบวัน, ทุกชั่วโมงต้องมีไม้, ถือไม้ละ ≤ 4 ชม., สุดท้ายเป็น EA

- Backtester ใหม่ `research/hourly_backtest.py`: ตัดสินใจทุกแท่ง H1 ปิด, เติมออเดอร์/MTM บน M15, หลายไม้พร้อมกัน (สูงสุด 4), risk 0.25 %/ขา, SL/TP เป็น ATR(14) ของ H1, ปิดเมื่อครบ 4 ชม., **set take-profit** (ปิดทั้งชุดของชั่วโมงนั้นเมื่อกำไรสุทธิรวมขาที่ปิดแล้ว ≥ X ATR), straddle lock, recovery hedge, เป้ารายวันเลือกได้
- EA `mql5/HourlySet.mq5` / `.ex5` (คอมไพล์ผ่าน 0 errors) ทำทุกโหมดข้างต้นบน H1 พร้อม daily target/stop, DD throttle, hard stop, Discord — คู่มือใน `mql5/README.md`
