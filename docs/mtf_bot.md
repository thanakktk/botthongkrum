# บอท Multi-Timeframe (MTF): D1/H4/H1 บอกทิศ → เข้าที่ M15 — ผลทดสอบและ EA

อัปเดต 2026-09-23 · ไฟล์: `research/mtf_backtest.py` (backtester), `mql5/MTF.mq5` / `MTF.ex5` (EA, คอมไพล์ 0 errors),
รายงาน `reports/mtf_M15*.txt`, `reports/mtf_M5.txt`

## สรุปสั้น

- **แนวคิดใช้ได้จริง**: การให้ D1+H4+H1 ยืนยันทิศเดียวกันก่อน แล้วค่อยหาจังหวะย่อตัวบน M15 เปลี่ยน entry เดิม ๆ จากขาดทุน (PF 0.97) เป็นมีกำไร (PF 1.06–1.09) — HTF filter คือส่วนที่ให้ edge ไม่ใช่ตัว entry
- **ไม้บ่อยขึ้นมากเทียบกับรอ H1/H4**: ≈ 0.9–1.0 ไม้/วัน (บอท H4 ≈ 0.3 ไม้/วัน) ถือเฉลี่ย 5.5 ชม.
- **ต้นทุนคือตัวตัดสิน**: ด้วยต้นทุนแบบยุคปัจจุบัน (0.625 bps ของราคา = $0.25 ที่ทอง $4,000) ระบบบวกทั้ง in-sample และ out-of-sample; ด้วยต้นทุน $0.25 คงที่ย้อนไปยุคทอง $1,200 (ต้นทุนสัมพัทธ์แพงกว่า 3 เท่า) จะเท่าทุน (PF 1.01)
- **M5 แย่กว่า M15 ทุกแบบ** (PF 0.83–0.93) — สัญญาณรบกวนและต้นทุนต่อ R สูงกว่า ไม่แนะนำ
- ปี 2024–2026 ผลแรงเป็นพิเศษ (PF 1.2–1.5, +18 % / +39 %/ปี ที่ risk 0.5 %) แต่อย่าคาดหวังตัวเลขนี้ตลอด — ค่าเฉลี่ย 11 ปีคือ +6.6 %/ปี DD 15 %

## 1. กฎของบอท (ค่า default ของ EA)

**ทิศ (Higher TF)** — ดูแท่งที่ปิดแล้วล่าสุดของแต่ละ TF: D1, H4, H1
- ขึ้น = EMA20 > EMA50 และ close > EMA50 · ลง = ตรงข้าม · อื่น ๆ = กลาง
- ต้องมี **3 ใน 3 ทิศเดียวกัน** (`NeedVotes=3`) ถึงจะหาจังหวะเข้า (2/3 ทดสอบแล้วแย่กว่า)

**จังหวะเข้า (M15, แท่งปิดแล้ว)** — pullback:
- ภายใน 24 แท่งก่อนหน้า (6 ชม.) ราคาเคยแตะ EMA20 ของ M15 (ย่อตัว)
- แท่งล่าสุดปิดกลับมาฝั่งเทรนด์ของ EMA20 และปิดสูงกว่า high ของแท่งก่อน (แท่งยืนยัน) → BUY (mirror สำหรับ SELL)
- 1 ไม้ต่อ 1 รอบย่อตัว (ห่างจากไม้ก่อนอย่างน้อย 24 แท่ง), ถือทีละ 1 ไม้

**SL / TP**
- SL = ใต้ swing low ของ 24 แท่ง + 0.1 ATR(14,M15) จำกัดอยู่ระหว่าง 0.5–2 ATR (SL แบบ 1 ATR ล้วน ๆ แย่กว่ามาก)
- TP = 2R · ปิดเมื่อครบ 24 ชม. ถ้ายังไม่ถึง (ตัวเลือก: ไม่มีเวลา / ปิดเมื่อ H1 กลับทิศ — ผลใกล้กัน)
- risk 0.5 % ของ equity ต่อไม้, DD throttle, hard stop, เป้ารายวันเลือกได้, Discord ครบชุด (เปิด/ปิด/สรุปรายวัน)

## 3. EA `MTF.ex5` — ติดตั้ง

1. โหลด https://github.com/thanakktk/botthongkrum/raw/main/mql5/MTF.ex5 → วางใน `MQL5\Experts` → Refresh
2. เปิด Algo Trading + whitelist `https://discord.com` (Tools → Options → Expert Advisors)
3. เปิดกราฟ `XAUUSD-ECN` **M15** (EA ดู D1/H4/H1 เองผ่าน indicator handle) → ลาก `MTF` ลงกราฟ
4. Inputs: ค่า default = ตัวที่ทดสอบ; ใส่ `DiscordWebhook` (หรือกด Load เลือก `mql5/MTF_local.set` ที่เก็บ webhook ไว้ในเครื่องนี้)
5. ตรวจ Journal: `MTF init: entry tf=PERIOD_M15 bias D1=1 H4=1 H1=1 need=3 K=24 ...` และ Discord ได้ "EA เริ่มทำงาน (MTF)"

Inputs ที่ควรรู้: `NeedVotes` (3), `K` (24), `RR` (2.0), `MaxHoldHours` (24, 0 = ไม่จำกัด), `ExitOnH1Flip`, `Side`, `RiskPct` (0.5), `DailyTargetPct/DailyStopPct`, `SummaryHour`, `MagicNumber` 747001

## 4. ข้อควรระวัง

1. edge เฉลี่ย +0.06R/ไม้ บาง: ปีที่ทองไม่มีเทรนด์ (2017–2020) เท่าทุนถึงลบเล็กน้อย ห้ามเพิ่ม risk เกิน 0.5–1 %
2. ต้นทุนจริงต้องต่ำ: ถ้าสเปรด+slippage เกิน ~$0.4/oz ที่ราคาปัจจุบัน edge หายหมด (เทียบผล $0.25 คงที่ในยุคทองถูก) — ใช้บัญชี ECN สเปรดต่ำ, หลีกเลี่ยงช่วงข่าว
3. Strategy Tester ของ MT5 ใช้ข้อมูล VT Markets ซึ่งขอบวัน/ชั่วโมงอาจต่างจาก CSV ที่ทดสอบ 1–2 ชม. ตัวเลขจะไม่ตรงเป๊ะ ทดสอบใน demo ก่อนอย่างน้อย 1 เดือน
4. ไม่ได้ทดสอบร่วมกับบอทตัวอื่นในบัญชีเดียว — ถ้ารันคู่กับ H4Trend/quantum ไม้จะซ้อนทิศเดียวกัน ความเสี่ยงรวมเพิ่ม
